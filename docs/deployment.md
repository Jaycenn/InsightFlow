# Deployment

No public deployment is claimed. Docker Compose provides a local, reproducible PostgreSQL + FastAPI + Nginx-hosted React stack. Copy `.env.example` to `.env`, set `POSTGRES_PASSWORD` and a long random `JWT_SECRET`, then run `docker compose up --build`. The backend waits for PostgreSQL health, applies `alembic upgrade head`, and starts Uvicorn. The frontend is served at port 5173; Nginx proxies `/api` and `/health` to the backend.

For separate hosting, build the frontend with `pnpm build` and serve `frontend/dist` with a static host such as Vercel. Set `VITE_API_URL` to the HTTPS API origin when not proxying requests. Run the backend on a Python-compatible host such as Render or Railway with `DATABASE_URL`, `JWT_SECRET`, `CORS_ORIGINS`, and `MAX_UPLOAD_MB`. Use managed PostgreSQL; apply `alembic upgrade head` before routing traffic to a new backend version. `/health` provides a lightweight liveness response.

Use HTTPS end to end. Set CORS to the exact frontend origin. Keep secrets in the platform's secret manager, not source control. Back up PostgreSQL regularly, including uploaded file bytes, and test restore. Review each autogenerated migration before deployment. If a schema migration cannot be reversed safely, restore from backup and redeploy a compatible app version rather than assuming downgrade is lossless. For scale, move file bytes to object storage and imports to a queue/worker. Configure database connection limits, observability, and rate limiting before serving untrusted public traffic.
